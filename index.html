[ RESULT 01 ]

Real-Time Neural Signal Decoding Accuracy

97.3% accuracy

Our system achieved 97.3% classification accuracy on EEG motor imagery signals using a custom lightweight CNN running on edge IoT hardware — processing raw brainwave data in under 50ms latency.

[ RESULT 02 ]

Edge Inference Latency & Throughput

<50ms end-to-end

From electrode capture to decoded intent, the full pipeline runs in under 50 milliseconds. The edge device processes 256 channels of EEG data at 250Hz with zero cloud dependency.

[ HOW IT WORKS ]

Convolutional Neural Network on Raw EEG

We trained a compact 1D-CNN on the BCI Competition IV dataset, optimized with quantization-aware training to run natively on a Raspberry Pi 4 with a Coral TPU accelerator.

  • 4-class motor imagery classification
  • Bandpass filtering (8-30 Hz) for mu/beta rhythms
  • Common Spatial Pattern (CSP) feature extraction
  • TFLite model: 1.2MB, 12ms inference
[ ARCHITECTURE ]

Edge-First Pipeline Design

The system uses a multi-stage pipeline: raw signal acquisition, real-time preprocessing, on-device inference, BLE-broadcast of decoded commands to any connected actuator.

  • OpenBCI Cyton board (8-channel, 250Hz)
  • Raspberry Pi 4 + Google Coral USB Accelerator
  • BLE 5.0 for low-latency command relay
  • WebSocket dashboard for live visualization
